# โครงสร้างระบบทั้งหมด

กลับไปที่ [[00_Home]]

## แนวคิดหลัก: แยก "สมอง" ออกจาก "หน้าตา"

ใน Addon เก่าหลายตัว โค้ดปุ่มกดกับโค้ดคำนวณมักเขียนปนอยู่ในไฟล์เดียวกัน ทำให้เวลาเพิ่มหน้าต่างใหม่หรือแก้บั๊กต้องตามแก้หลายที่

ใน `FullDestruc_Tool` เราแบ่งโค้ดออกเป็น 3 ชั้นชัดเจน:

1. **ชั้นสมองหลัก (`addon/core/`)** — ทำหน้าที่คำนวณ ตัดโมเดล จัดโฟลเดอร์ และเก็บสถานะ **ห้ามมีโค้ดวาดปุ่มหรือหน้าตาปนอยู่** (รวมถึง `draw_engine.py` ที่ใช้ NumPy คำนวณรูป 2D -> 3D แยกจาก Blender และ `zone_registry.py` ที่เป็นแหล่งความจริงเดียวของโซนทั้งหมด)
2. **ชั้นคำสั่งกด (`addon/ops/`)** — เป็นตัวกลางใน Blender (`bpy.types.Operator`) ที่รับการกดจากผู้ใช้แล้วส่งต่อให้ `core/` ทำงาน รวมถึงวาด GPU Overlay (Zone Grid & Focus Highlight)
3. **ชั้นหน้าตา (`addon/ui/`)** — เรียกใช้คำสั่งจาก `ops/` และ `core/` ชุดเดียวกันทั้งหมด:
   - **แถบขวา (`panel_n.py`)**: อยู่ใน N-Panel ชื่อแท็บ `FullDestruc` สำหรับตั้งค่าละเอียด
   - **เมนูลอยตามเมาส์ (`floating_menu.py`)**: กดปุ่มลัด `Alt+Shift+Q` เพื่อให้เมนูเด้งขึ้นตรงจุดที่เมาส์ชี้
   - **หน้าต่างแยก (`qt_window.py`)**: หน้าต่าง Python แยกด้วย `PySide6` ลากไปวางอีกจอได้ รองรับลากสลับชั้น Layer ดูรายละเอียดที่ [[ระบบเชื่อมหน้าต่าง_PySide6]]
   - **เครื่องมือบนจอ 3D (`cutter_gizmo.py`, `wheel_menu.py`, `draw_overlay.py`)**: ปุ่มเฟือง + เมนูวงแหวนบนกล่องตัด, เลือกแกน 3D ต่อกล่องชิดขอบ, และกระจกใสวาดเส้น 2D -> Extrude
