# ระบบกล่องเก็บต้นฉบับลับ (Protected Vault)

กลับไปที่ [[00_Home]] | ดูต้นตอปัญหาที่ [[สรุปบั๊กเดิมจาก_Red_Panda]]

## ปัญหาเดิมที่ต้องแก้ให้ขาด
ใน `Red_Panda` โฟลเดอร์ `Originals_*` ชอบเด้งกลับมาบังหน้าจอเอง และถ้าผู้ใช้ไปติ๊กปิดโฟลเดอร์ `Originals_*` ไว้ พอกด **Apply** ก็จะเกิด Error หรือได้โมเดลเปล่า

## วิธีทำงานแบบใหม่ (`addon/core/vault.py`)
1. **ติดป้ายห้ามยุ่ง (`fdt_protected = True`)**:
   - ทุกโฟลเดอร์เก็บต้นฉบับ (`FDT_Vault_<ชื่อชุด>`) และโมเดลต้นฉบับข้างในจะถูกติดป้าย `fdt_protected = True`
   - โมดูล `core/zone_shield.py` มีฟังก์ชัน `is_protected_collection()` และ `is_protected_object()` ให้ระบบ [[Zone_Manager]] เรียกเช็กก่อนเสมอ -> **ระบบเปิด/ปิดโซนจะไม่มีวันไปเปิดโฟลเดอร์ต้นฉบับขึ้นมาบังหน้าจออีก**
2. **การประเมินผลอย่างปลอดภัยตอนกด Apply (`temporary_vault_evaluation`)**:
   - เมื่อผู้ใช้กด Apply ต่อให้โฟลเดอร์ต้นฉบับจะถูก **ซ่อนตา (`hide_viewport`)** หรือ **ติ๊กปิดกล่อง (`exclude`)** อยู่ก็ตาม
   - ตัวช่วย `with temporary_vault_evaluation(context, vault_col):` จะจดจำสถานะเดิมของโฟลเดอร์ไว้ก่อน -> แอบเปิดให้ Blender คำนวณรอยตัด (Depsgraph) ชั่วคราวในเสี้ยววินาที -> คัดลอกร่างจริงออกมา -> แล้วคืนค่าซ่อน/ปิดติ๊กกลับเหมือนเดิมใน `finally` เสมอ
   - ผลลัพธ์คือ **กด Apply ได้ตลอด ไม่มี Error และหน้าจอไม่เปลี่ยน**
