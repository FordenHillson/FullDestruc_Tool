# ระบบเชื่อมหน้าต่าง PySide6 (External Python Window)

กลับไปที่ [[00_Home]] | ดูภาพรวมที่ [[โครงสร้างระบบทั้งหมด]]

## ทำไมต้องใช้ `PySide6`
จากการตรวจสอบ Python ของ Blender 5.2 บนเครื่องนี้ พบว่า:
- `PySide6` มีติดตั้งพร้อมใช้อยู่แล้ว (ไม่ต้องติดตั้งไลบรารีเพิ่ม)
- `tkinter` ไม่มีในชุด Blender 5.2

## วิธีทำให้หน้าต่างแยกไม่ทำให้ Blender ค้าง (`addon/ui/qt_bridge.py`)
1. **ห้ามเรียก `app.exec()` แบบค้างหน้าจอ**: เพราะจะทำให้ Blender หยุดทำงานทันที
2. **ใช้ตัวตั้งเวลาของ Blender (`bpy.app.timers`)**: ให้ `bpy.app.timers.register()` เรียก `app.processEvents()` ทุก ๆ ประมาณ 0.03 วินาที เพื่ออัปเดตหน้าต่างแยกไปพร้อม ๆ กับการทำงานของ Blender
3. **ไม่ขวาง `Reload Scripts`**: เราไม่ใช้ Modal Operator ค้างไว้สำหรับหน้าต่าง Qt ดังนั้นผู้ใช้สามารถกด Reload Scripts ใน Blender ได้ตามปกติ และเมื่อปิด/รีโหลด Addon ระบบจะปิดหน้าต่างและหยุด Timer ให้สะอาด
4. **ระบบสำรองอัตโนมัติ (Fallback)**: หากนำ Addon ไปเปิดบนเครื่องที่ไม่มี `PySide6` โค้ดจะข้ามการเปิดหน้าต่างแยกไปอย่างปลอดภัย โดยที่ N-Panel และเมนูลอยยังทำงานได้ 100%
