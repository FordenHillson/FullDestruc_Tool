# Cleanup Tools (แผนเฟส 4)

กลับไปที่ [[00_Home]]

## รายการเครื่องมือ 4 ตัว (จาก list F.txt)
1. **Find Texture**: ทำดัชนีไฟล์ในโฟลเดอร์ SVN ครั้งเดียวแล้วค้นหาทันที ไม่ต้องเดินวนทั้งโฟลเดอร์ซ้ำทุกไฟล์
2. **Del by material**: รองรับขอบเขตการทำงาน 4 แบบ:
   - `Object` (เฉพาะชิ้นที่เลือก)
   - `Collection` (เฉพาะโฟลเดอร์ที่เลือก)
   - `Suffix` (เฉพาะชิ้นที่ลงท้ายชื่อตามที่กำหนด)
   - `Scene` (ทั้งฉาก)
3. **Replace Material**: แทนที่ Material พร้อมตัวเลือกเปิด/ปิดการจับคู่ `.001` และรวมช่อง Material ที่ซ้ำให้อัตโนมัติ
4. **Fix mat slots**: แก้เฉพาะชิ้นที่มีหน้าพังหรือช่องว่างจริง ไม่เติมช่องเกิน และลบช่องว่าง (`None`) ทิ้งให้สะอาด
