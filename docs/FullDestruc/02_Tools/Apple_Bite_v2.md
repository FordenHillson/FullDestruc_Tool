# Apple Bite v2.5 (ระบบตัดตึกและแบ่งโซน)

กลับไปที่ [[00_Home]] | [[ระบบ_Rust_Engine_และ_GPU_Preview]] | [[ระบบปิดหน้าตัด_และ_ปิดผิวทะลุอัตโนมัติ]] | [[ระบบกล่องเก็บต้นฉบับลับ]]

## จังหวะการใช้งานแบบพาเดินทีละขั้น (3 ขั้นตอน)

### ขั้นที่ 1: เริ่มตัด, กลับไปแก้ หรือ รีเซ็ตกลับต้นฉบับ
- **ยังไม่เลือกอะไร**: ขึ้นข้อความบอก *"คลิกเลือกโมเดลตึกในจอ 3D (เลือกหลายชิ้นพร้อมกันได้)"*
- **เลือกโมเดลปกติ**: ปุ่มเปลี่ยนเป็น **"Start Apple Bite (X ชิ้น)"**
- **คลิกโดนชิ้นที่เคยตัดหรือ Apply ไปแล้ว**:
  - กด **Cut Further** เพื่อตัดซอยเพิ่มต่อจากชิ้นเดิมได้
  - กด **Re-edit Previous** เพื่อย้อนกลับไปแก้รอยตัดรอบก่อน
  - กด **Reset to Original** *(ปุ่มสีแดงพร้อมหน้าต่างยืนยัน)* เพื่อไล่ลบงานตัดทั้งหมดที่เกี่ยวข้อง (รวมถึงการกด Cut Further หลายรอบ) แล้วคืนโมเดลต้นฉบับแท้ๆ กลับมาที่ฉากหลักอย่างสะอาด

### ขั้นที่ 2: วางและจัดการตัวตัด (Cutters)
รองรับการสร้างตัวตัด 4 แบบ:
1. **+ Add Box**: วางกล่องตัดตรงกึ่งกลางตึกที่เลือกทันที (พร้อมขยับด้วย `G / R / S`)
2. **+ Use Mesh**: นำโมเดลที่ปั้นเองมาเป็นตัวตัด
3. **Click Place (`Ctrl + คลิกขวา`)**: จิ้มวางกล่องตัดเอียงตามผิวผนังที่ชี้
4. **Draw Cutter (`2D -> Extrude`)**: วาดรูปบนกระจกใสทับจอ 3D (คลิกจุดต่อจุดหรือลากเส้นอิสระ Freehand) ปรับจำนวนจุดได้ แล้วดึงความลึกเป็นก้อนตัน 3D (คำนวณแยกด้วย `core/draw_engine.py` + `ui/draw_overlay.py`)

เครื่องมือจัดการตัวตัด:
- **Cutter Layers (ลำดับชั้นเหมือน Photoshop)**: ตัวตัดใหม่จะอยู่ชั้นบนสุด (`#1`) และได้พื้นที่ส่วนที่ทับซ้อนก่อน สลับลำดับได้ 3 วิธี:
  1. ลากสลับในหน้าต่าง Python หรือกด `▲ / ▼` ใน N-Panel
  2. **แถบโค้งทางขวาของเมนูวงล้อ (`▲ Up` / `▼ Down`) + โหมดจิ้มเลือกกล่องเป้าหมายใน 3D**: คลิก `▲ Up` (สีเขียว) หรือ `▼ Down` (สีส้ม) บนแถบขวาของวงล้อ → ชี้แล้วคลิกซ้ายที่กล่องเป้าหมายในจอ 3D เพื่อแทรกกล่องต้นทางไว้เหนือหรือใต้กล่องนั้นทันที (หมุนกล้องด้วยปุ่มกลางได้ปกติ, กด `ESC`/คลิกขวาเพื่อยกเลิก)
- **ปุ่มเฟืองบนกล่องตัด (Radial Wheel Menu & 3D Axis)**:
  - ตรงกลางวงล้อโชว์ทั้งชื่อ Zone และเลข Layer ปัจจุบัน (เช่น `Zone B • Layer #2`)
  - 9 ปุ่มหลัก: `Next Box` (ต่อกล่องตามแกน 3D), `Zone` (**คลิก** เพื่อปิดวงล้อแล้วเปิด popup ค้นหาโซนจาก Registry — มีปุ่ม New / Rename / Delete ร่วมอยู่), `Rough`, `Apply`, `Delete`, `Mute`, `New Box`, **`View: All / Piece / Hole`** (รูปดวงตา — **คลิก** เพื่อปิดวงล้อนี้แล้วเปิด**วงล้อโหมดมองใหม่**ตรงตำแหน่งเมาส์ มี 4 ช่อง: `All` / `Piece Only` / `Hole Only` / `Hole + Wire`; เมื่อ**โฮเวอร์**ช่อง `Hole` ช่องจะแยกเป็น 2 ทางเลือกย่อย `Solid` = Hole Only และ `Wire` = Hole + Wire; คลิกช่องใดช่องหนึ่งเพื่อเปลี่ยนทันที, คลิกนอกวงล้อ/กด `ESC` หรือคลิกขวาเพื่อปิด), `Draw Cut`

### Zone Registry (โซนที่ผู้ใช้สร้างเอง)
- ทุก dropdown zone (N-Panel, เมนูลอย, หน้าต่าง Qt, วงล้อ) อ่านจาก Registry เดียวกันใน `addon/core/zone_registry.py`
- โซนมี **Key ที่คงที่** (`A`…`Z` หรือ `z_0001`…) กับ **Token ที่แก้ได้** (`ID-A#B`, `VIS-A#B`, `ID-A_VIS-A#B`, ข้อความอิสระ)
- เปลี่ยนชื่อ token ไม่ทำให้ cutter/piece หลุด เพราะ property เก็บ key เสมอ
- built-in A–Z ลบไม่ได้ (เป็น fallback ของไฟล์เก่า) แต่เปลี่ยนชื่อ/sี/base ได้; custom zone ลบได้ถ้าไม่มี cutter/piece ใช้งาน
- ปุ่ม `Change Zone` บนเฟืองวนตามลำดับ Registry เต็ม (`A`…`Z` แล้วค่อย custom ตามลำดับสร้าง)
- รายละเอียด: [[Zone_Manager]] | [[CONTEXT]] | [[0001-zone-registry]]

- **สลับมุมมองแบบ 0 ms (`All` | `Piece Only` | `Hole Only`)**:
  - **`All`**: แสดงทั้งตึกหลัก + ชิ้นที่ตัด + กล่องตัด
  - **`Piece Only`**: แสดง **เฉพาะชิ้นที่ตัดตาม Zone ของกล่องที่เลือกอยู่** (กด `Shift+คลิก` เพื่อดูหลาย Zone พร้อมกันได้) หมุนดูรอบชิ้นและขยับ/ดึงแก้กล่องตัดได้ลื่น 60–144 FPS
  - **`Hole Only`**: แสดงเฉพาะตัวตึกหลักที่มีรูแหว่ง + กล่องตัด
  - **`Hole + Wire`**: ตึกหลัก solid ตามปกติ + ส่วน mesh ที่ซ่อนอยู่ในกล่องตัด (ชิ้นที่ตัด) เป็น wireframe สีโซน + สลับ 0 ms เช่นกัน
- **แก้กล่องตัดใน Edit Mode แบบสด + เห็นจุดกลางหน้า (`*`) ชัด**:
  - ดึงหน้า/เบเวล/แก้จุดของกล่องตัดใน Edit Mode แล้วพื้นที่ Zone Grid และรอยตัดอัปเดตตามทันที
  - จุดกลางหน้า (`*`), เส้นขอบ และสีส้มของหน้าที่เลือกจะลอยเด่นด้านหน้าตึกเฉพาะตอนอยู่ใน Edit Mode พอออกกลับ Object Mode เส้นกล่องจะถูกบังตามความลึกจริงไม่รกตา
- **Zone Grid Overlay & Focus Highlight**:
  - เปิด/ปิด `Zone Grid` หรือปรับขนาดตารางได้ทันทีแบบ 0 ms โดยไม่คำนวณ Rust ใหม่

### ขั้นที่ 3: ปรับรอยตัด & จบงาน (Apply)
- ซ่อนไว้จนกว่าจะวางตัวตัดอย่างน้อย 1 อัน เพื่อไม่ให้หน้าต่างรก
- ปรับขอบขรุขระ (**Rough Edge** แบบทั้งหมดหรือเปิดแยกทีละตัวตัด), **Cut Material**, และขนาด **Texel UV**
- **ระบบปิดหน้าตัดอัตโนมัติ (เปิดไว้เป็นค่าเริ่มต้น)**:
  - `Auto-Fill Cut Gaps`: ปิดรูหน้าตัดที่ยังเปิดอยู่เฉพาะบนระนาบที่ตัด (ไม่ปิดหน้าต่าง ประตู หรือห้องกลวง)
  - `Close See-Through Backfaces`: สร้างผิวด้านในเชื่อมมุม (~2.8 มม.) ปิดผิวชั้นเดียวที่มองทะลุในห้องใต้หลังคา
- **ปุ่มกดปิดเองหลัง Apply (`Fill Cut Cap`)**:
  - ใน Object Mode: กด `Fill Cut Cap (Auto)` เพื่อสแกนปิดรูหน้าตัด + ผิวทะลุ
  - ใน Edit Mode: เลือกขอบรู (เพื่อปิดช่อง) หรือเลือกผิวชั้นเดียว (เพื่อสร้างผิวปิดด้านหลัง) แล้วกด `Fill Selected Cut Cap`
- แสดง **สรุปจำนวนชิ้นที่จะได้** ก่อนกด Apply (กด Apply จากใน Edit Mode ของกล่องตัดได้ทันที)
- งานเก็บละเอียดหลัง Apply: กู้คืน **Custom Split Normals** เดิมทุกจุด, สร้าง **`sharp_edge`** และ **`freestyle_edge`** ตามมาตรฐาน Blender 5.2
- หากย้อนกลับมา **Re-edit** หลัง Apply ไปแล้ว: ระบบจะซ่อน `FDT_Final_*` ชั่วคราว พอกด Apply รอบใหม่จะเขียนทับสะอาด (หรือถ้ากด **Cancel & Restore** ก็จะล้าง `FDT_Final_*` และคืนต้นฉบับให้สะอาดเช่นกัน)
