## แหล่งความจรงเดีีย

เรื่่องเรารของเหล็กทกุอย่างอยใน `addon/core/rebar_spline.py`, `rebar_generate.py`, `rebar_state.py`:

| ทับ | ความหมาย |
| --- | --- |
| **Rebar Generator** | ชดุเหล็กเทาดียว ตวัตวัจร่งค่อ `sid` ตวัยอใน `fdt_rebar_registry_json` (Scene) ชื่อกใน Outliner เปนเพียาเลเบล |
| **Rebar Tag** | จำนวนเท็มใน face attribute `fdt_rebar_group` ของ host mesh เปนตั่วสัดตั่วจร่งว่หน่าไหนเขากบชดุนี้ |
| **Rebar Buffer** | ชดุคาสงเครียบบน Scene (`fdt_rebar_settings`) แสดงเปน มม. ใน N-Panel ตัวเกบเปนเมตร |
| **Bend Spec** | ลายดัดของเหล็กรางเดีียว ท้งหมดอยใน `BendSpec` 1 ตวั (ไมเกบในไฟล เปนแคแคท่วกลางตอนสร้าง) |
| **Bend Scale** | ระยทางระหว่จังหวัดดัดยอย (wobble) — ยิ่เลก็ลายแกวงถี่ ยิ่ใหญโค้งสะอาดเชิงเดียว |

## ลายดัดและบด (Bend + Twist)

เหล็กท่โผลจากคอนกรตไมตรง: โค้งไปทิศทางเดีียวอยางลวน ๆ เหมือนลวดท่ถูกดัดดวยเคร่่อง แลววูบแกวงเลก็ ๆ บิดข่เกลียวแบบส่ม แตกำหนดไดดวย 3 คาสงเครียบท้งหมด

| คาสงเครียบ (UI) | เกบเปน | ตวัเทียบ |
| --- | --- | --- |
| **Bend (mm)** | `bending_strength` (เมตร) | 0 คือดตรง; 30 (ดฟอลต) คือปลายงอนนอย ๆ เหมือนเหล็กท่ถูกเศษคอนกริตทาบ |
| **Bend Scale (mm)** | `bend_scale` (เมตร, 50–1000, ดฟอลต 400) | ยิ่เลก็ปลายแกวงเปนคลืนถี่; 400 คื่อโค้งเรียบพอดีสำหรบเหล็กยาว 10–50 ซม. |
| **Seed** | `random_seed` (int) | เลขเดีวกน = ลายเหล็กเดีวกนทุกครง |
### รปแบบการดัด

ทำให่เหล็กดูลงตัวเหมื่อนเหล็กท่ถูทุบ (ไม่ใช่คลืน):

- **แท่งตรงเกือบท้งหมด โค้งอยางลวนเฉพาะปลาย** (arc เดียว, ตื่่้นกลางไม่มีคลืน) — ทิศดัดค่อมผลรวมของ bias + ส่ม, โค้งเร่มจากผิวคอนกริ่ตอยางลวนเท่่าต้งตามล้งเดืม และดัดมากทสสุดท่ปลาย
- **แรงดัดไม่เท่่ากันท้งแท่ง**: ส่ม 35–100% ของ Bend Amount (เอนไปขางนอย) — เหล็กสว่่นใหญ่ดัดนอย ๆ บางแท่งดัดหนั่่ง
- เล็กนอยออกนอกระนาบ (±3% ของ Bend) — ทำให่แท่งไม่อย่ในระนาบท่เดี่่ยมหมด
- **เหล็กยาว → ดัดมาก, สั่่ง → ดัดนอย**: Bend Amount ใช่เต็มกำลังกตอเมื่่อชวงท่โผล่ยาว 35 ซม.; สั่่งกวาน่ดัดนอยตามสัดส่ว่น
- **ความเนียนออโตเมตริก**: ตอน bake ระบบจะเพิ่่่มจำนวนจุดในชวงท่ดัดให่พอ (สูงสุด 40) — โค้งเลยไม่หักหวั่่มุมแม่ Smooth Steps ต่า

### ทิศดัด

ทศิหลกยังคงกฎเดม: normal ของหน่า + แรงหน่ง + หลีกอปสรรค เปนตั่วดอม เดี่ยวกนดวยเวกเตอรส่ม 1 ทิศของแต่ละราง

### Twist (บดข่เกลียว)

ไมมสไลเดอรบด:

```
twist_limit = min(π, bend_amount / 0.32 · π)
```

- ดัด 0 → บด 0 (เหล็กตรงต่งไป)
- ดัด 160 mm → บดสูงสดุ ±90°
- ดัด 320 mm ข่นไป → ดักท่ ±180° (คร่่งตั่ว)

แต่รางไดคาบดส่มในชวง ±limit จาก RNG ของรางน้น frame ของ profile ส่เหล่บหมุนต่งแต 0 ท่ผิวคอนกรตไปจนถงคาเต็มท่ปลาย — เหน็นข่เกลียวชัดเพราะ profile เปนส่เหล่บ

### ความซำผล

```
rng = random.Random(f"fdt-rebar-{seed}:{index}")
```

(ใช string seed ไมใช tuple เพราะ string ถูก รวมกบ SHA-512 ให deterministic ทุกระบบ ทุก version Python — tuple ถูกฏออกใน Python ใหม)

- Seed เดีวกน → ชดุเหล็กเดีวกนทุกอยาง (รวมบิดดวย) ตอนกด Re-apply
- รางท่ n ม่ลายไมข่นอยูกัรางท่รองหน้าง → เลิกรางไหนไมทำใหลายรางอ่่นเปลีย่่น
- ปุมเตาเตา (dice) ขางช่อง Seed ส่มเลขใหม 0–999999 คาสงเครียบท้งหมดอ่่นไมเคล่่น

## ผลตอกระบบ

- **Debris** (คอนกรตท่เกาะเหล็ก) คำนวณจากจุดสุดทายของเส่น — เหล็กดัดไปไหน เศษตามไปเท่านน บดไมไดผลตอตำแหน่เศษ
- **GPU preview** (fast drag) แสดงเส่นดัดจริง แตะลากดูรปได; ข่เกลียวเหน็นตอน Bake ทังแท่ง
- **Bake** = commit ตาม invariant เดิม (คาสงเครียบถูล็อค เป็นเมตร ใน registry) — ลายดัดถูกเกบใน mesh ไมไดเกบเปนพารามเตอรเพ่
