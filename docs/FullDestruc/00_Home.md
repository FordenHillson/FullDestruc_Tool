# FullDestruc_Tool — คลังความรู้และแผนพัฒนา

> [!info] เกี่ยวกับคลังนี้
> คลังนี้เก็บแผนโครงสร้าง บทเรียนจากบั๊กเก่า และคู่มือการทำงานของ Addon **FullDestruc_Tool** (สำหรับ Blender 5.2 ขึ้นไป) เพื่อหยิบกลับมาดูได้ตลอดเวลาและไม่ลืมเหตุผลของการออกแบบ

## สารบัญหลัก

### 0. ภาพรวมและเปรียบเทียบ
- [[00_Summary_Comparison]] — **สรุปผลระบบใหม่ v2.5 และตารางเปรียบเทียบกับระบบเดิม** (พร้อมตัวเลขวัดจริงและภาพประกอบ)

### 1. สถาปัตยกรรมและโครงสร้าง
- [[โครงสร้างระบบทั้งหมด]] — แผนผังการแยก "สมองหลัก" ออกจาก "หน้าตา 3 แบบ"
- [[ระบบ_Rust_Engine_และ_GPU_Preview]] — เอนจินตัด Rust v1.5.1 + วาด Multi-Layer PBR Shader 4 ชั้นบน GPU 60–144 FPS + Edit Mode สด
- [[ระบบปิดหน้าตัด_และ_ปิดผิวทะลุอัตโนมัติ]] — ปิดรูหน้าตัด (ไม่ปิดหน้าต่าง/ห้อง) + ปิดผิวชั้นเดียวที่มองทะลุ (Backface Culling)
- [[ระบบกล่องเก็บต้นฉบับลับ]] — วิธีเก็บชิ้นต้นฉบับไม่ให้โผล่มาบังและไม่พังตอน Apply
- [[ระบบเชื่อมหน้าต่าง_PySide6]] — วิธีเปิดหน้าต่างแยกนอก Blender แบบลื่นไม่ค้าง

### 2. เครื่องมือแต่ละหมวด
- [[Apple_Bite_v2]] — ระบบตัดตึกหลายชิ้นพร้อมกัน + เมนูวงล้อปรับ Layer + โหมดดูเฉพาะชิ้น (`Piece Only`) (**เฟส 1**)
- [[Zone_Manager]] — ระบบจัดการโซน `ID`/`VIS` + สลับดู `LOD`/`Collider`/`Socket` (**เฟส 2**)
- [[Naming_and_Validate]] — ตั้งชื่อ ตรวจชื่อ แก้บั๊ก `Fix socket` และรวมชิ้น (**เฟส 2**)
- [[Cleanup_Tools]] — หา Texture, ลบตาม Material (4 ขอบเขต), แทนที่ Material, แก้ช่องว่าง (**เฟส 4**)
- [[Batch_Future]] — พื้นที่จองสำหรับระบบรันอัตโนมัติ (**เฟส 5**)

### 3. บทเรียนและข้อควรระวัง (กันลืม)
- [[สรุปบั๊กเดิมจาก_Red_Panda]] — ต้นตอของบั๊กเก่าทุกตัวที่เจอและวิธีป้องกันถาวร
- [[ข้อควรระวัง_Blender_5_2]] — จุดที่เปลี่ยนใน Blender 5.2 (เช่น `freestyle_edge`, `Smooth by Angle`)

### 4. บันทึกการทดสอบและรายงาน Performance
- [[รายงานปรับปรุง_UI_และ_Performance_v2.0-v2.3]] — **รายงานสรุปการปรับปรุง UI, Debug Benchmark Score, Rust Engine v2.0–v2.1.1 และ G-Buffer Imposter Drag v2.3**
- [[บันทึกผลทดสอบแต่ละเฟส]] — ผลรันชุดทดสอบอัตโนมัติในแต่ละรอบ
