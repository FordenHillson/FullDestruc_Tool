### เฟส 1.5 (Rust Engine v1.5.1 + Multi-Layer PBR GPU Preview + Auto Cap Fill & Backface Liner + Wheel Layer Picker) — 2026-11-23
- **สภาพแวดล้อม**: Blender 5.2.0 LTS (Windows 11, 24 Cores) + โมเดลตึกทดสอบจริง (7,255 polys, scale `0.01`, single-sided attic + custom split normals)
- **ผลลัพธ์**:
  1. **Rust Engine v1.5.1 (`cargo test --release`)**: **PASS 8 / 8** (รวม `test_single_sided_internal_wall_no_fins`, ทดสอบหนัก 19,200 tris ใช้เวลา `3.99 ms`, ตัดครีบสามเหลี่ยมกลางห้องใต้หลังคา `6,129 cm²` หาย 100%)
  2. **Zero-Switch Multi-Layer PBR GPU Preview**: ลากกล่องจริงได้ **60–144 FPS** (Main thread write `~1.0–1.7 ms`, Rust background `~13–20 ms`), สลับ `All / Piece Only (แยกตาม Zone) / Hole Only` และเปิด/ปิด `Zone Grid` ได้ทันที **0 ms**
  3. **Custom Split Normals & Sharp Edges**: `degen = 0`, `has_custom_normals = True`, `top_nrm_max_err = 0.000000`
  4. **Cut-Plane Auto-Fill & Backface Liner (`test_cap_fill.py`)**: **PASS 4 / 4**
     - Test 1: ปิดรูหน้าตัดบนกำแพงสเกล cm สนิท (`open_edges = 0`), ช่องหน้าต่างยังเปิดครบ (`open_edges = 4`)
     - Test 2: ห้องกลวงไม่เผลอปิด (`filled = 0`)
     - Test 3: Apply จริง + Manual Fill ทั้ง Object Mode และ Edit Mode (11 ขอบรวมจุดเรียงเส้นตรง → ปิดสนิท 9 หน้า, `open_edges = 0`, `sharp_edges = 19`, `custom_nrm = True`)
     - Test 4: ปิดผิวทะลุห้องใต้หลังคา 5 ด้าน + ทดสอบกดซ้ำได้ `0` หน้าซ้ำ (Idempotent) + ทดสอบเลือกผิวใน Edit Mode
     - **โมเดลตึกทดสอบจริง**: ชิ้นตัดแยก (`_FDST_ID-A`) ปิดผิวทะลุครบ **34 หน้า** (รอบ 2 เหลือ `0` จุดทะลุ), ตัวตึกหลัก (`_Cut`) ปิดผิวทะลุเฉพาะรอยตัด **60 หน้า**
  5. **Edit Mode Cutter Live Sync + Auto `show_in_front` + Display Modes (`test_edit_mode_cutter_sync.py`)**: **PASS** (ขยับหน้าใน Edit Mode อัปเดต Rust + Wireframe ทันที, กด Apply จากใน Edit Mode ได้, สลับ `ALL / PIECES / MAIN` ผ่านครบ)
  6. **Wheel Right Layer Wing + 3D Target Picker (`test_wheel_layer_reorder.py`)**: **PASS 2 / 2** (`hit_test_layer_wing` แยก `ABOVE / BELOW` ชัดไม่ทับวงล้อหลัก, `move_cutter_relative_to` แทรกลำดับ `[A, C, B] -> [B, A, C]` และย้ายเฉพาะ 1 กล่องเมื่อมีหลายกล่องใน Zone เดียวกันถูกต้อง)
