# สรุปบั๊กเดิมจาก `Red_Panda` (จดไว้กันทำซ้ำ)

กลับไปที่ [[00_Home]]

## 1. Apple Bite เข้า/ออกโหมดรวน
- **สาเหตุเดิม**: ใช้ตัวแปร `ab_is_active` ค้างไว้ และพยายามเรียก `select_set(True)` กับชิ้นต้นฉบับที่อยู่ในโฟลเดอร์ที่ซ่อนอยู่ ทำให้เกิด `RuntimeError`
- **วิธีป้องกันใหม่**: ใช้ `core/session.py` คุมสถานะแบบชัดเจน และเช็กสถานะโฟลเดอร์ก่อนเลือกวัตถุเสมอ ไม่เรียก `select_set` กับวัตถุที่ซ่อนอยู่

## 2. โฟลเดอร์ `Original` เด้งมาบังหน้าจอเอง
- **สาเหตุเดิม**:
  1. ฟังก์ชันเปิดโฟลเดอร์ของ Apple Bite ดันไปสั่งเปิดโฟลเดอร์ลูกทั้งหมด (รวม `Originals_*`)
  2. ระบบเปิด/ปิดโซน (`RP_Toggle_ Object_Type`) วิ่งสแกนทุกโฟลเดอร์ พอเห็นชื่อ `_FDST_ID-` ใน `Originals_*` ก็สั่งเปิดตาโฟลเดอร์นั้นขึ้นมาทับหน้าจอ
- **วิธีป้องกันใหม่**: ใช้ [[ระบบกล่องเก็บต้นฉบับลับ]] ติดป้าย `fdt_protected = True` และให้ระบบโซนข้ามโฟลเดอร์ที่มีป้ายนี้เสมอ

## 3. กด Apply ตอนปิด `Original` แล้ว Error
- **สาเหตุเดิม**: ไม่ได้อัปเดตภาพฉาก (Depsgraph) และถ้าโฟลเดอร์ `Original` ถูกติ๊กปิด (`exclude`) Blender จะไม่คำนวณรอยตัดให้ ทำให้ได้โมเดลเปล่าหรือพัง
- **วิธีป้องกันใหม่**: ใช้ตัวช่วย `temporary_vault_evaluation` แอบเปิดคำนวณเฉพาะเสี้ยววินาทีที่อบร่างจริง แล้วพับเก็บคืนใน `finally` เสมอ

## 4. บั๊ก `Fix socket` ใน Validate Name (สำหรับเฟส 2)
- **สาเหตุเดิม**:
  1. ปุ่มซ่อนและทำงานเฉพาะโหมด Object
  2. ลำดับการรันไปเปลี่ยนชื่อหน้า (`Name Base`) ก่อน ทำให้คำว่า `socket_` หายไป พอถึงคิว `Fix socket` จึงหาไม่เจอ
  3. ไม่คุมความยาวชื่อไม่เกิน 63 ตัวอักษร ทำให้ชื่อใน Blender กับ `EBT_SocketName` ไม่ตรงกัน
- **วิธีป้องกันใหม่**: จะทำในเฟส 2 ให้รันได้ทุกโหมด แยกกลุ่ม `socket_` ไว้ก่อนเปลี่ยนชื่อหน้า และคุมความยาวไม่เกิน 63 ตัวอักษรพร้อมซิงก์ค่า `EBT_SocketName`
